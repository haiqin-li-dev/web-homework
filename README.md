# web-homework
软件工程web前端实验作业
作业一：本次实验成功完成了“王者荣耀大电影简介”网页的制作，严格遵循HTML规范实现了文档结构与页面内容的完整设计。在文档结构上，正确使用 <!DOCTYPE html> 声明文档类型，设置 lang="zh-CN" 适配中文环境，通过 <head> 标签配置了字符编码与页面标题，确保网页在不同浏览器中能正常解析与显示。在页面内容上，通过 <h1> 设置主标题，利用 float 浮动结合 overflow:hidden 清除浮动，实现了电影海报与基本信息、预告片与演员列表的左右并排布局，同时使用 <strong> 、 <em> 、 <b> 、 <u> 等文本标签丰富了内容的排版层次。此外，通过 <hr> 分割不同模块、 <a> 标签实现新窗口跳转的超链接，进一步完善了页面的交互性与可读性。实验过程中，重点掌握了浮动布局的使用方法与清除浮动的技巧，解决了内容换行与排版错乱的问题，最终完成了一个结构清晰、布局合理的电影简介网页。
通过本次网页制作实验，我对HTML的核心语法与页面布局逻辑有了更深入的理解。在实践过程中，我深刻体会到了浮动布局的灵活性与局限性： float 能快速实现元素的并排效果，但也会导致元素脱离文档流，需要通过 overflow:hidden 等方式清除浮动，这让我意识到前端布局需要兼顾美观与稳定性。同时，我也认识到了语义化标签的重要性，合理使用 <h1> 、 <p> 、 <ul> 等标签不仅能提升页面的可读性，还能优化搜索引擎的抓取效果。在遇到排版问题时，我通过反复调试与查阅资料，逐步掌握了问题排查的方法，这培养了我的耐心与解决问题的能力。本次实验让我感受到了前端开发的趣味性与逻辑性。
作业2：本次实验完成用户注册网页的开发，综合运用HTML、CSS与JavaScript技术搭建注册表单页面。页面借助nav标签实现导航栏，点击导航链接可唤起弹窗，弹窗内结合无序列表、有序列表、定义列表分别展示注册注意事项、注册步骤以及常见问题，实现弹窗与列表的组合运用。页面包含文本框、密码框、单选框、复选框、下拉菜单、文件上传、文本域等多种表单控件，完成必填项校验、手机号格式约束、协议复选框锁定等功能。JavaScript部分主要依托课本知识，同时借助AI工具辅助理解相关语法逻辑，解决弹窗显示异常、布局错位、交互逻辑出错等问题，提升开发效率。通过本次实验，我熟悉各类表单标签的用法，理解HTML结构、CSS样式、JS脚本三者协同工作的原理，掌握弹窗交互的开发思路，夯实前端网页开发基础，也认识到自身在JS逻辑调试方面存在不足。
完成本次注册页面实验后，我对前端网页开发有了更加切实的理解。网页制作不只是标签的简单堆砌，还需要兼顾页面布局排版与基础交互效果。本次实验的难点集中在导航栏、弹窗与各类列表的协同实现，最开始出现弹窗点击无响应、页面布局混乱等问题，自行调试很难定位根源。JavaScript相关内容我主要依靠课本学习，很多逻辑知识点借助AI工具辅助理解梳理，顺利完成弹窗开关、点击空白关闭弹窗等交互效果。实验也让我体会到表单细节的重要性，密码确认、正则校验、复选框限制这些细节，都是真实网页必不可少的部分。AI是很好的学习辅助，但不能直接复制代码，要读懂代码背后的逻辑。之后我会多练习表单与JS交互，提升独立查错能力，巩固前端基础，编写结构规范、交互完善的网页代码。
